# KAN-900 - Поле Email на формі реєстрації

Джерело: https://neoversity-ak.atlassian.net/browse/KAN-900
Тип: Task
Згенеровано: 2026-09-26

## Мета

Додати на форму реєстрації обовʼязкове поле для введення email із валідацією формату й довжини.

## Межі

- У межах задачі: поле Email (label, placeholder, обовʼязковість), правила валідації та тексти помилок, момент спрацювання валідації, відображення помилки.
- Поза межами задачі: в описі: "Перевірка унікальності email на бекенді не входить у цю задачу, див. KAN-901".

## Вимоги

- Поле типу `email` з label "Email" та зірочкою обовʼязковості
- Placeholder "name@example.com"
- Валідація виконується при сабміті форми
- Порожнє поле: помилка "Email is required"
- Значення без символу `@` або без домену після `@`: помилка "Enter a valid email address"
- Більше 254 символів: помилка "Email must not exceed 254 characters"
- Розбіжність між джерелами: таблиця валідації в описі "Більше 254 символів"; коментар Дмитра Лисенка, 2026-09-18: "максимум 255 символів". Не узгоджено в Jira.
- Пробіли на початку й у кінці значення обрізаються перед валідацією
- Помилка відображається під полем червоним текстом
- Після виправлення значення і повторного сабміту помилка зникає

## Додаткові вимоги (з коментарів)

- Валідацію також виконувати при втраті полем фокусу (blur), а не лише при сабміті (коментар Олени Коваль, 2026-09-20: "інакше користувач дізнається про помилку тільки наприкінці форми"; до цього в описі була лише валідація при сабміті, рішення розширено).

> Ця секція лише для ознайомлення з контекстом.
