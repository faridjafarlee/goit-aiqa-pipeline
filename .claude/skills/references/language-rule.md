# Правило мови (спільне для всіх скілів пайплайну)

- Артефакти (`Task Runs/<ISSUEKEY>/*.md`) і повідомлення в чаті пишуться українською.
- Дослівно, без перекладу і без зміни регістру/пунктуації зберігаються:
  - тексти інтерфейсу: label, placeholder, назви кнопок, пунктів меню, статусів;
  - повідомлення про помилки та інші copy-тексти (наприклад, `"Full name is required"`);
  - назви полів, ендпоінтів, ролей, ключі задач Jira, ідентифікатори (REQ-ID, TC-ID).
- Цитати з тікета, коментарів і вкладень подаються мовою оригіналу, пояснення до них пишуться українською.
- Якщо користувач у чаті явно просить іншу мову, артефакт лишається українською, а відповідь у чаті пишеться мовою запиту.
