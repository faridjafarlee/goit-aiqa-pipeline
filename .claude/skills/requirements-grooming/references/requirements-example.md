# KAN-900 - Вимоги

Контекст: Task Runs/KAN-900/KAN-900-context.md
Згенеровано: 2026-09-26

## Мета

Додати на форму реєстрації обовʼязкове поле для введення email із валідацією формату й довжини.

## Вимоги

- REQ-1: Поле типу `email` з label "Email" та зірочкою обовʼязковості
- REQ-2: Placeholder "name@example.com"
- REQ-3: Валідація виконується при сабміті форми
- REQ-4: Порожнє поле: помилка "Email is required"
- REQ-5: Значення без символу `@` або без домену після `@`: помилка "Enter a valid email address"
- REQ-5a: Значення з кількома символами `@` вважається невалідним: помилка "Enter a valid email address" (узгоджено з користувачем)
- REQ-6: Більше 254 символів: помилка "Email must not exceed 254 characters"
- REQ-7: Пробіли на початку й у кінці значення обрізаються перед валідацією
- REQ-8: Помилка відображається під полем червоним текстом
- REQ-9: Після виправлення значення і повторного сабміту помилка зникає
- REQ-10: Валідація також виконується при втраті полем фокусу (blur)
